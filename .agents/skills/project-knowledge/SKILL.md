# Project knowledge activation

This repository uses the environment-provided `project-knowledge` skill for
initialization, updates, and audits. Maintainers must keep the repository
documentation skeleton (`docs/INDEX.md`, `PRODUCT.md`, `ACCEPTANCE.md`,
`CURRENT.md`, and `CODEMAP.md`) indexed and current, preserve raw evidence, and
record substantial changes under `docs/maintenance/` and `docs/decisions/`.

The full skill instructions are supplied by the Codex environment; this file is
the repository-local activation and scope pointer, not a second copy of those
instructions.
