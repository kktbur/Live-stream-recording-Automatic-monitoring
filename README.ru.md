# Reco Box

[简体中文](README.md) | [繁體中文](README.zh-TW.md) | [English](README.en.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Português](README.pt.md) | [Русский](README.ru.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

Reco Box — локальное приложение Windows x64 для автоматического мониторинга и записи трансляций. Оно включает карточный интерфейс, групповые команды, сегментацию, упаковку в MP4, историю, журналы, системный трей и импорт старых настроек. Текущая версия: `0.2.1`. Учётные записи не нужны, cookies не сохраняются.

## Загрузка и установка

Загрузите `RecoBox-Setup-0.2.1.exe` и файл `.sha256.txt` из Releases. Установщик не подписан. Для LiveMe включена проверенная минимальная среда Node.js v24.20.0 LTS.

## Платформы

Существующие: Douyin, Kuaishou, Bilibili, Xiaohongshu, TikTok, YouTube и JD. Taobao отключён, поскольку закреплённый анализатор требует авторизованную сессию.

Новые Beta: Twitch, SOOP Global, CHZZK, TwitCasting, SHOWROOM, BIGO LIVE, 17LIVE, LiveMe, Picarto и Shopee Live. До выпуска необходима проверка публичных примеров: эфир/офлайн, URL потока и короткая запись. Ограниченные комнаты возвращают ошибку анонимного доступа; вход никогда не выполняется. Kick, Facebook Live и Instagram Live не входят в план.

## Запись, прокси и языки

- Сегментация по умолчанию выключена; файлы нумеруются 1, 2, 3…, последний сохраняет фактическую длительность.
- Путь: `стример / дата / время начала / видео`; TS можно без перекодирования упаковать в MP4.
- Глобальный прокси наследуют только новые комнаты; у каждой комнаты может быть свой. Допускаются HTTP/HTTPS без логина и пароля; прокси используется анализатором и FFmpeg и не записывается в журнал.
- Десять языков переключаются мгновенно. Новая установка следует поддерживаемому языку Windows; старая база остаётся на упрощённом китайском; выбор сохраняется.

## Конфиденциальность и безопасность

База, журналы и настройки остаются локальными. Некоторые запросы исходного анализатора отключают проверку TLS; используйте доверенную сеть. См. [PRIVACY.md](PRIVACY.md), [SECURITY.md](SECURITY.md) и [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Исходный код и сборка

Требуются Windows x64, Python 3.12 и PowerShell 7. Установите `.[dev]`, подготовьте `runtime/ffmpeg`, для LiveMe запустите `tools/prepare_node.ps1`. Затем `pytest tests -q`, `packaging/build.ps1` и `packaging/build_installer.ps1`. Бинарные файлы не входят в Git.
